# Release notes — CaRSEL-CVD v0.2.0

This is the initial GitHub-ready research-prototype release. It includes a FastAPI/Python model and API, English HTML/CSS/JavaScript frontend, all nine real interface screenshots, separate labeled concept mockups, tests, sample *schema* CSV, documentation, and a GitHub Actions workflow.

**Scientific limitation:** This implementation is a label-free-inference research variant, not an independently verified reproduction of the original CaRSEL-CVD article implementation, and is not clinically validated. No clinical dataset, patient data, pretrained model, or measured clinical performance is bundled.

All concept UI metrics are illustrative and are not research findings. Consult `docs/SOFTWAREX_CHECKLIST.md` before any manuscript submission.
