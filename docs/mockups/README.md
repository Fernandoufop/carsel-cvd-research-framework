# Conceptual UI designs — not experimental results

These nine generated UI mockups illustrate a target interface design. They are NOT generated by the executable backend, and every numerical performance metric, date, user, dataset size, recommendation, or patient-level value appearing in them is illustrative and unverified. The original mockups also portray cholesterol and glucose as mmol/L; the executable system correctly uses ordinal dataset encodings 1,2,3, so these visuals must not be used to document the input schema.

For journal figures, use screenshots of the actual application in docs/actual_screens or new screenshots created from the trained released code, with real reproducible results and accurate feature codes. None of the mockup performance charts should be presented as measured evidence.
