DEVELOPMENT-ONLY SUPERVISION

Model Training

Fit the CaRSEL-CVD Python cascade on labeled CSV data using frozen, label-free test-time inference.

HTTP training disabled by default

Training configuration

Training protocol

1. Validate encoded predictors and outcome
2. Stratified holdout partition
3. RF / NB / GB out-of-fold stage selection
4. Development-set confidence calibration
5. Final fixed cascade + KNN fallback
6. Holdout evaluation and archived report

Alternative EAWV weighting is not implemented as a claim of equivalence to the original argmax selector.
